# Global-Super-Store-Dashboard
The Global Superstore dashboard provides a high-level view of sales, orders, and profitability across regions, markets, segments, and time. It tracks key KPIs such as Total Sales (62M), Total Orders (25K), Total Profit (1M), Average Order Value (2.47K), and Profit Margin (2.37%), giving a quick snapshot of overall business performance.
Interactive filters for Region, Market, Category, Segment, Order Priority, and Month allow users to drill down into specific areas. The visuals highlight monthly order trends, city-wise sales distribution, segment-wise order contribution, market-wise profit, and sales by ship mode, helping identify growth patterns, top-performing markets, and customer behavior. Overall, the dashboard supports data-driven decision-making by combining performance monitoring with actionable insights.
